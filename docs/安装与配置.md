# 安装与配置

Frostrail mod管理器是一个 EXE，用来安装、开关、设置和更新 Mod。作者 Yuuka。非官方，与游戏开发商无关。

## 下载

到 [Releases](https://github.com/yakumo-hx/Frostrail-UE4SS-Mods/releases/latest) 下载：

- `FrostrailModManager-<版本>.exe`：管理器。放在哪个文件夹都行，文件名也可以随便改。
- `UE4SS-FrostrailCore-<版本>.zip`：前置，下面的功能 Mod 都要用到它。
- 想用的功能 Mod ZIP，见下面的表。ZIP 不用解压。

管理器在 Windows 10 22H2 和 Windows 11 上双击就能用。它用的是系统自带的 .NET Framework 4.8，不用另装东西。

## 安装

1. 退出游戏。
2. 打开管理器，在顶部选游戏目录。也可以点“浏览…”，选游戏 EXE 或游戏里的任意文件夹。
3. 把 Core 和想用的功能 Mod 一起拖进窗口，也可以点“安装 → 本地 ZIP…”。
   - 一起装时，管理器会先装前置。
   - 如果缺前置，Mod 会装上，但先保持关闭。
4. 有的 Mod 装的时候会弹出作者的提醒，看完再选。
5. 从 Steam 正常启动游戏。管理器可以关掉。

不想手动下载 ZIP，也可以在管理器里点“安装 → GitHub 链接…”，粘贴 `https://github.com/yakumo-hx/Frostrail-UE4SS-Mods`，勾选要装的包（默认全选），一次装好。

别人做的 Lua、C++、PAK Mod 也能用管理器装。用不到前置的 Mod 不需要装 Core。作者怎么打包，见[包规范 v2](包规范-v2.md)。

## 包与功能

| 包 | 作用 |
| --- | --- |
| UE4SS-FrostrailCore | 前置：固定版本的 UE4SS、公共支持库、游戏内 F8 设置窗口 |
| 辅助 | 二段跳、高亮、R 拿取、头灯、基础负重、快存与格子锁、菜单暂停、同列车供料、O 回列车；另有耐久开关、种植和物品生成倍率 |
| 容量 | 堆叠上限默认 ×10；分拣台输入 15 格、输出 10 格，均可调整；物品重量不变 |
| 自动保存 | 默认每玩 10 分钟保存一次；从 Esc 返回主菜单或退出游戏前也保存 |
| 控制台 | 房主按 Y 搜索、分类、翻页领取物品；一次性恢复体温或血量，搭配辅助可回列车 |
| 新物品 | 芝士汉堡、薯条、甜甜圈；微波炉、显示器、收音机、键盘可在分拣台回收，均有独立模型和图标 |
| 伐木 0.1.0 | 近战砍倒站立的树，默认每棵获得原木 2、树枝 3 |

从旧版换过来，先在管理器里卸载快存与格子锁、房主菜单暂停、同列车供料、种植、堆叠、分拣台这六个旧包，再装新的辅助和容量。旧包设置和锁格位置不转入新包，需要的改键请在游戏里重新设置。

辅助里的功能按组设置。描边高亮、R 拿取、头灯、快存与格子锁、菜单暂停和供料默认开启，整块高亮默认关闭，基础负重仍为 100。种植默认关闭，打开后下次启动游戏生效：分拣台投入 1 个莓果、果实或蘑菇，默认 600 秒产出 5 个，共七种，配方可调。

**高亮（辅助 0.6.0 起）：** “描边高亮”和“整块高亮”是两个独立开关，F8 可即时切换，也可以同时开启。两种样式共用四个类别开关、距离和扫描间隔。

- 描边保留模型贴图，颜色固定：物品青绿、容器黄、地窖和敌人红；使用游戏原样的粗细和穿墙效果，墙后显示外圈。准星对准时会与原生交互描边混色，移开后恢复。
- 整块高亮在整个模型上盖一层颜色，下面四项“颜色（整块）”只影响它。
- 旧设置 `highlight` 不再读取，也不迁移。更新后描边默认开启；以前关闭高亮的玩家，如需继续关闭，可在 F8 关掉“描边高亮”。两个开关都关时停止高亮扫描。

快存默认把背包里的物品存入 20 米内已有同类物品的玩家箱子；锁格不会被快存走，整理背包时也保留位置。快存和锁格默认没有按键，可在游戏控制设置里绑定。“快存”是把东西存进附近的箱子，不是保存游戏。

**回列车（辅助 0.5.0 起）：** 默认按 O，回到当前列车上原有的玩家出生点；可在原生控制设置里改键。仅单人或房主可用，F8 可关闭。列车行驶中会读取出生点的当前位置；在地窖中返回会解除地窖状态。出生点未加载或被挡住时提示失败，不传到旧坐标。控制台 0.2.1 起也可点右侧“回列车”，需要同时安装辅助并开启此功能。

**二段跳（辅助 0.7.0 起）：** 默认开启。第一次跳起后，空中松开再按原跳跃键，可再跳一次；落地后恢复次数。保留原版单次跳跃高度和重力，原生改键继续生效。管理器或 F8 中的“启用二段跳”可单独关闭。多人尚未验证。

**耐久（辅助 0.5.0 起）：** 两项独立开关，默认都关闭，只由房主生效。

- **设备防寒损**：工作台、分拣台、研究台和加热器不再受寒冷损耗。攻击、主动拆解和正常维修照常；已经损坏的设备不会自动修好。在 F8 即时切换，关闭后恢复设备原有的冷损设置。伊甸引擎、车厢、箱子和野外拆解物不在此范围内。
- **工具和武器不磨损**：把原生物品耐久消耗倍率设为 0，也影响使用这条规则的衣物。需要重新启动游戏，不补回已有磨损。关卡没有耐久规则时，状态页会多出“防腐环境”；已有耐久规则时保留原来的条目，例如只有腐蚀时仍只显示“腐蚀环境”。这些规则的说明仍是原版文字：防腐为“所有物品的耐久度损耗降低 20%。”，腐蚀为“所有物品的耐久度损耗增加 20%。”，不随 Mod 变化；开启后实际不磨损，不能按这段文字判断。关闭或卸载后重新启动游戏，恢复原版关卡倍率。

**物品生成：** 在管理器里改，退出并重新启动游戏后生效；两个倍率默认都是 1，这一组不另设开关。

- **数量倍率**：1–10 的整数。箱子、柜子和房屋拾取点新刷出的可堆叠物品，一次给的数量乘上它；一格一件的工具、武器和图纸不变。
- **刷出机会倍率**：1–4，允许小数。刷新点这次有东西的机会乘上它，最多到必出；各物品之间的抽取比例不变。
- 原版关卡本来有“杂物堆”规则时，表内数量和刷出机会按原版 1.5 再乘玩家倍率。固定数量的拾取点另外乘数量倍率。
- 只影响以后新生成的物品。已生成的物品和搜过的箱子不会再翻倍或补货。森林自然生成的树枝、原木，植物采集，拆设备和制作的产出不变。
- 数量受当前堆叠上限影响：箱子按原版方式分堆，地面拾取点最多生成一堆，超出的数量封顶。需要更大堆叠时可搭配容量包。
- 调大任意倍率后，原生状态页的关卡规则列表会显示“杂物堆”。这是临时启用原版规则的显示效果。

**同列车供料：**

- 制作界面里的材料数量是“背包 + 列车上所有储物箱”的合计，够了就能点制作。箱子在哪节车厢都行，不用站在旁边。
- 点制作时，缺的材料会从箱子搬进背包，再由游戏照常制作。你背包里原有的材料先用。
- 关掉制作界面（游戏也会在这时停止制作）后，搬进来没用完的材料会自动放回列车上的箱子，优先放进已有同类物品的箱子；箱子放不下的留在背包。
- 制作途中游戏崩溃或被强制关掉，搬进来的材料会留在背包里，不会丢。
- 可以在辅助设置里开关。关掉供料时，已借进背包但没用完的材料仍会退回。只在单人游戏或你自己当主机时生效。

**容量要注意：** 降低设置、关闭或卸载前，先在容量包还开着的时候拆开超量堆叠、清空分拣台额外格子，再保存，否则可能丢东西。

**新物品：** 食物从厨房和杂物掉落中获得，可直接食用，不能制作；微波炉带厨房标签，其余三种杂物放入杂物掉落。七种物品均使用 Kenney CC0 模型和独立图标，说明最后一行写“来自 Mod：新物品”；四种杂物归在游戏的“垃圾”分类。汉堡、薯条、甜甜圈的重量分别为 0.6、0.4、0.2，基础堆叠上限都是 10。微波炉、显示器、收音机、键盘的重量分别为 3、2、0.8、0.5，基础堆叠上限分别为 3、3、10、10。四种杂物带回列车，放进分拣台回收：

| 杂物 | 一次产出 | 基础时间 |
| --- | --- | ---: |
| 微波炉 | 金属废料 8、零件 2、铜废料 2 | 20 秒 |
| 显示器 | 塑料废料 6、零件 2、铜废料 2 | 15 秒 |
| 收音机 | 金属废料 2、零件 2、铜废料 2 | 10 秒 |
| 键盘 | 塑料废料 4、铜废料 2 | 10 秒 |

新物品只加入以后的随机掉落，不会补满已经搜过的箱子。关闭或卸载后再读档，本包物品会消失，食物效果会失效；原来的食物记录可能还会占一个食物槽，到时间后消失。

新物品包是靠替换原版的 6 张掉落表（`LT_Tier_1` 到 `LT_Tier_5`、`LT_Tutorial`）加进去的，替换版是在原版表的基础上加了几行。所以：

- 游戏更新后，如果官方改了这几张表，新物品包会把它们换回旧版。游戏更新后先关掉新物品包，等它出新版。
- 别的 Mod 如果也改这几张表，两个只有一个生效。

辅助里的菜单暂停可以单独关闭。用 Esc 关背包等窗口不会暂停。多人游戏时只有房主的菜单会暂停，所有人都会停住；其他玩家打开菜单不会暂停。多人暂停还没用真实的多人游戏测过。

**控制台：** 配套 Core 0.3.2。只在单人游戏或你当房主时使用，按 Y 打开，Y 或 Esc 关闭；可以在游戏的“设置 → 控制”里改键。面板打开时游戏照常运行。

- 控制台 0.2.0 起，可在背包、工作台或箱子界面上按 Y 打开。Esc 只关控制台，回到原来的页面，保留制作会话；搜索框里有光标时也一样。搜索打字不会让角色移动或触发游戏动作。F8 设置窗口与控制台互斥。
- 左列选择分类，搜索框按当前游戏语言的物品名称筛选；下方箭头翻页。Mod 加的物品另有“Mod 物品”页签，格子角上有标记。鼠标停在图标上显示名称，左键领取 1 个，按住 Shift 点击领取多个（默认 10 个，可在管理器或 F8 的控制台设置里改），由游戏按堆叠上限分好。底部显示实际进背包的数量；没进包的查看脚边。
- 格子下方两个圆形按钮分别恢复体温、恢复血量，都是点一下恢复一次；体温恢复后仍会照常下降。
- “回列车”按钮使用辅助的回列车功能，发起传送时关闭控制台。未安装辅助或关闭功能时会提示开启。
- 第一次打开时，图标会一个个出现，其余物品的图标在后台接着准备，几秒内就绪；刚打开就翻页可能还要等一下。之后翻页、再打开都直接显示，换地图或回主菜单后重新准备。
- 能找到已加载内容包的物品。第一版不列出模块化武器和防毒面具定义及部件，不提供文字命令。

**自动保存：**

- 用的是游戏自己的存档：身上和箱子里的东西、列车位置、关卡进度都会保存。读档后人会出现在列车上或开局起点，和游戏自己的存档一样，不会回到保存时站的位置。
- 暂停、读图、主菜单里的时间不算进 10 分钟。改了开关或间隔会重新计时。
- 游戏会保留最近 10 份存档，读档时可以任选一份，自动保存也算在里面。间隔越短，能回到的时间越近：默认 10 分钟大约能回到 100 分钟前。想留更早的存档，就把间隔调长。
- 屏幕上提示“已保存”就是真的存好了。保存失败会提示失败，不拦着你退出。游戏崩溃或被强制关掉时来不及保存。
- 角色死亡、还没重生时不存，等重生后再存。这时候退出会提示无法保存，读档回到上一次的存档。
- 它只适配现在这个版本的游戏。游戏更新后它会自动停用，日志里写明原因，等自动保存出新版再更新。
- 只在单人游戏或你自己当主机时保存。多人还没完整测过。

## 伐木 0.1.0

安装 `FrostrailWoodcutting` 和前置后，站立的健康树、枯树、病树都能用近战砍。树桩、倒木和灌木不算。照常挥击，耐力和耐久仍由游戏扣除。

| 武器 | 砍倒一棵所需的有效命中 |
| --- | ---: |
| 废铁棒 | 4 |
| 原始木棒 | 6 |
| 金属撬棍、金属锤、金属扳手 | 8 |
| 简易撬棍、废料锤、简易扳手、木槌 | 10 |
| 其他近战，包括火把和枪托 | 15 |

换武器不会丢掉已经砍的进度，比如木棒 3 下再换废铁棒 2 下即可砍倒。未砍完的进度不保存，重新进入战役后从头算。

默认每棵给原木 2、树枝 3，直接放进背包，放不下的落在地上。F8 中的“原木数量”“树枝数量”改完立即影响下一棵；可填 0 或更大的整数。

砍倒处留下树桩，没有 E 采集提示，也不会被辅助高亮。树桩随游戏存档保存；关闭伐木包后读档，原树恢复、树桩消失，已拿到的原版木材保留，仍能保存。安装或关闭包前先退出游戏。多人尚未实测。

## 开关和设置

- **开关：** 在左边列表里勾选。
- **加载顺序：** 用箭头调整。不经过 UE4SS 加载的包（比如只有 PAK 的）不参与排序，排在最后。
- **连带开关：** 开关一个 Mod 时，如果它的前置或依赖它的 Mod 要跟着一起变，管理器会列出来，确认一次就行。
- **改设置：** 选中 Mod 后，在右边改。勾选、按回车、离开输入框或改完表格，设置就存好了，没有“保存”按钮。
- **恢复默认：** 只恢复这一页上的设置，格子锁位置这类页面上没有的数据不受影响。

游戏开着时，管理器里的安装、开关和设置都不能改，日志照常能看。

在游戏里按 F8 能直接改一部分设置（管理器里标着 F8 的那些），点“应用并保存”马上生效。其余设置下次启动游戏时生效。F8 窗口的文字跟随游戏语言，显示中文或英文。

按键在游戏的“设置 → 控制”里改。辅助默认 R 全部拿取、F 开关头灯、O 回列车；快存、锁格和 F8 也在那里改。

辅助 0.3.1 起，按 R 拿空容器后会自动关闭容器和背包；容器里还有东西没拿走时，界面保持打开。R 只在单人游戏或你当主机时生效。

## 更新

- 在管理器里点“检查更新”。有新版本的 Mod 会标出来，可以在详情里单个更新，也可以点“全部更新”。版本号和已装的不同就会提示，所以退回旧版本也可以。
- 也可以下载新的 ZIP 直接拖进管理器。
- 不管哪种方式，开关、顺序和设置都会保留。
- 管理器本身有新版时，点“检查更新”后顶部会出现“更新管理器到 x”。点一下，管理器会下载新版、替换自己并重新打开（0.3.2 起）。如果管理器放在不能写入的文件夹里，就到 Releases 下载新的 EXE 手动替换。

“安装 → GitHub 链接…”可以粘贴仓库首页，也可以粘贴 `tree/分支/目录` 这样的目录链接。仓库里有多个 ZIP 时，会列出来让你选。不需要 GitHub 账号。如果提示请求太多，过一会儿再试，或者下载 ZIP 拖进来。

## 卸载

在详情里点“卸载…”，看完作者的提醒再确认。勾上“保留设置”会留下它的 `config.json`，重装后设置还在。依赖它的 Mod 会被关闭，并显示缺少前置。具体删哪些文件、留哪些，见[卸载会删什么](包规范-v2.md#卸载会删什么)。

卸载不会改你的存档，也不会替你拆开超量的堆叠。

## 出问题时

- **列表里的 ⚠：** 这个 Mod 上次启动游戏时出错了。选中它，详情里会显示第一条错误。
- **“日志”页：** 先列出错的地方，下面是完整日志。可以只看上次启动、管理器操作或某一个 Mod，也可以按级别筛选、搜索文字。
- **导出诊断包：** 点“导出诊断包”会生成一个 ZIP，里面有摘要、管理器日志、UE4SS.log 的最后一段和所选 Mod 的日志。导出的文件里，你的用户目录和游戏路径会被替换掉，也不会自动上传。反馈问题时附上它。

## 文件存在哪

- 安装记录和包缓存：游戏目录里的 `FrostrailModData/`。游戏目录搬到哪，它跟到哪。
- 管理器的界面设置（语言、窗口大小、上次选的游戏目录等）：`%LocalAppData%/Yuuka/FrostrailModManager/ui.json`。
- 每个 Mod 的设置：它自己文件夹里的 `config.json`。
