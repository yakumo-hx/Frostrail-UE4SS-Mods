# 安装与配置

Frostrail mod管理器是一个 EXE，用来安装、开关、设置和更新 Mod。作者 Yuuka。非官方，与游戏开发商无关。

## 下载

到 [Releases](https://github.com/yakumo-hx/Frostrail-UE4SS-Mods/releases/latest) 下载：

- `FrostrailModManager-<版本>.exe`：管理器。放在哪个文件夹都行，文件名也可以随便改。
- `UE4SS-FrostrailCore-<版本>.zip`：前置，下面的功能 Mod 都要用到它。
- 想用的功能 Mod ZIP，见下面的表。ZIP 不用解压。

管理器在 Windows 10 22H2 和 Windows 11 上双击就能用。它用的是系统自带的 .NET Framework 4.8，不用另装东西。

## 安装

1. 退出游戏。
2. 打开管理器，在顶部选游戏目录。也可以点“浏览…”，选游戏 EXE 或游戏里的任意文件夹。
3. 把 Core 和想用的功能 Mod 一起拖进窗口，也可以点“安装 → 本地 ZIP…”。
   - 一起装时，管理器会先装前置。
   - 如果缺前置，Mod 会装上，但先保持关闭。
4. 有的 Mod 装的时候会弹出作者的提醒，看完再选。
5. 从 Steam 正常启动游戏。管理器可以关掉。

不想手动下载 ZIP，也可以在管理器里点“安装 → GitHub 链接…”，粘贴 `https://github.com/yakumo-hx/Frostrail-UE4SS-Mods`，勾选要装的包（默认全选），一次装好。

别人做的 Lua、C++、PAK Mod 也能用管理器装。用不到前置的 Mod 不需要装 Core。作者怎么打包，见[包规范 v2](包规范-v2.md)。

## 包与功能

| 包 | 作用 |
| --- | --- |
| UE4SS-FrostrailCore | 前置：固定版本的 UE4SS、公共支持库、游戏内 F8 设置窗口 |
| 辅助 | 穿墙高亮物品、没拿空的容器、地窖入口和敌人；打开容器按 R 全部拿走；F 开关头灯；可调基础负重 |
| 快存与格子锁 | 一键把背包里的东西存进附近已有同类物品的箱子（默认 20 米内）；锁住的格子不会被存走，整理背包时也不动 |
| 分拣台 | 输入格扩到 15、输出格扩到 10，数量可调 |
| 种植 | 往分拣台放 1 个莓果、果实或蘑菇（共七种），600 秒后变成 5 个；配方可改 |
| 堆叠 | 物品堆叠上限 ×10，可按类别调整；单个物品的重量不变 |
| 房主菜单暂停 | 按 Esc 打开菜单时游戏暂停，进到设置等页面也保持暂停；点继续或关掉菜单就恢复。一个人玩同样生效 |
| 自动保存 | 默认每玩 10 分钟保存一次；从 Esc 返回主菜单或退出游戏前也保存。开关和间隔可在管理器或 F8 里改 |

“快存”是把东西存进附近的箱子，不是保存游戏。

**堆叠要注意：** 关闭、卸载或调低倍率之前，先在 Mod 还开着的时候，把超过原版上限的堆拆开并存档。否则多出来的数量会丢。

暂停包没有设置项。用 Esc 关背包等窗口不会暂停。多人游戏时只有房主的菜单会暂停，所有人都会停住；其他玩家打开菜单不会暂停。多人暂停还没用真实的多人游戏测过。

**自动保存：**

- 用的是游戏自己的存档：身上和箱子里的东西、列车位置、关卡进度都会保存。读档后人会出现在列车上或开局起点，和游戏自己的存档一样，不会回到保存时站的位置。
- 暂停、读图、主菜单里的时间不算进 10 分钟。改了开关或间隔会重新计时。
- 游戏会保留最近 10 份存档，读档时可以任选一份，自动保存也算在里面。间隔越短，能回到的时间越近：默认 10 分钟大约能回到 100 分钟前。想留更早的存档，就把间隔调长。
- 屏幕上提示“已保存”就是真的存好了。保存失败会提示失败，不拦着你退出。游戏崩溃或被强制关掉时来不及保存。
- 角色死亡、还没重生时不存，等重生后再存。这时候退出会提示无法保存，读档回到上一次的存档。
- 它只适配现在这个版本的游戏。游戏更新后它会自动停用，日志里写明原因，等自动保存出新版再更新。
- 只在单人游戏或你自己当主机时保存。多人还没完整测过。

## 开关和设置

- **开关：** 在左边列表里勾选。
- **加载顺序：** 用箭头调整。不经过 UE4SS 加载的包（比如只有 PAK 的）不参与排序，排在最后。
- **连带开关：** 开关一个 Mod 时，如果它的前置或依赖它的 Mod 要跟着一起变，管理器会列出来，确认一次就行。
- **改设置：** 选中 Mod 后，在右边改。勾选、按回车、离开输入框或改完表格，设置就存好了，没有“保存”按钮。
- **恢复默认：** 只恢复这一页上的设置，格子锁位置这类页面上没有的数据不受影响。

游戏开着时，管理器里的安装、开关和设置都不能改，日志照常能看。

在游戏里按 F8 能直接改一部分设置（管理器里标着 F8 的那些），点“应用并保存”马上生效。其余设置下次启动游戏时生效。F8 窗口的文字跟随游戏语言，显示中文或英文。

按键在游戏的“设置 → 控制”里改。辅助默认 R 全部拿取、F 开关头灯；快存、锁格和 F8 也在那里改。

辅助 0.3.1 起，按 R 拿空容器后会自动关闭容器和背包；容器里还有东西没拿走时，界面保持打开。R 只在单人游戏或你当主机时生效。

## 更新

- 在管理器里点“检查更新”。有新版本的 Mod 会标出来，可以在详情里单个更新，也可以点“全部更新”。版本号和已装的不同就会提示，所以退回旧版本也可以。
- 也可以下载新的 ZIP 直接拖进管理器。
- 不管哪种方式，开关、顺序和设置都会保留。
- 管理器本身有新版时，点“检查更新”后顶部会出现“更新管理器到 x”。点一下，管理器会下载新版、替换自己并重新打开（0.3.2 起）。如果管理器放在不能写入的文件夹里，就到 Releases 下载新的 EXE 手动替换。

“安装 → GitHub 链接…”可以粘贴仓库首页，也可以粘贴 `tree/分支/目录` 这样的目录链接。仓库里有多个 ZIP 时，会列出来让你选。不需要 GitHub 账号。如果提示请求太多，过一会儿再试，或者下载 ZIP 拖进来。

## 卸载

在详情里点“卸载…”，看完作者的提醒再确认。勾上“保留设置”会留下它的 `config.json`，重装后设置还在。依赖它的 Mod 会被关闭，并显示缺少前置。具体删哪些文件、留哪些，见[卸载会删什么](包规范-v2.md#卸载会删什么)。

卸载不会改你的存档，也不会替你拆开超量的堆叠。

## 出问题时

- **列表里的 ⚠：** 这个 Mod 上次启动游戏时出错了。选中它，详情里会显示第一条错误。
- **“日志”页：** 先列出错的地方，下面是完整日志。可以只看上次启动、管理器操作或某一个 Mod，也可以按级别筛选、搜索文字。
- **导出诊断包：** 点“导出诊断包”会生成一个 ZIP，里面有摘要、管理器日志、UE4SS.log 的最后一段和所选 Mod 的日志。导出的文件里，你的用户目录和游戏路径会被替换掉，也不会自动上传。反馈问题时附上它。

## 文件存在哪

- 安装记录和包缓存：游戏目录里的 `FrostrailModData/`。游戏目录搬到哪，它跟到哪。
- 管理器的界面设置（语言、窗口大小、上次选的游戏目录等）：`%LocalAppData%/Yuuka/FrostrailModManager/ui.json`。
- 每个 Mod 的设置：它自己文件夹里的 `config.json`。
