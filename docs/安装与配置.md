# Frostrail mod管理器 0.3.0：安装与配置

作者：Yuuka。本版提供一个管理器 EXE、UE4SS-FrostrailCore 前置和五个独立功能包。

## 从 GitHub 下载

在 [Releases](https://github.com/yakumo-hx/Frostrail-UE4SS-Mods/releases/latest) 下载 `FrostrailModManager.exe`，以及 Core 和需要的功能 Mod ZIP。EXE 可以放在任意文件夹，ZIP 不用解压。

也可以只下载 EXE，在管理器中点“安装 → GitHub 链接…”，粘贴仓库地址 `https://github.com/yakumo-hx/Frostrail-UE4SS-Mods`，从六个包中选择 Core 和想用的功能包。

## 启动与安装

在 Windows 10 22H2 或 Windows 11 上双击 `FrostrailModManager.exe`，不需要开发工具。管理器使用系统 .NET Framework 4.8 或兼容的 4.8.1。

1. 退出 Frostrail。
2. 在顶栏选择游戏目录；也可以“浏览…”选择游戏 EXE 或其子目录。选择后立即生效。
3. 一次把 Core 和想用的功能包拖入窗口，也可以用“安装 → 本地 ZIP…”。多包一起装会先处理前置；缺少前置的包会装上但保持关闭。
4. 按包作者的提示作出选择，然后从 Steam 正常启动游戏。管理器可以关闭。

普通第三方 Lua、C++、PAK 包也可安装。不使用公共支持库的 Mod 不需要 Core。作者打包方法见[包规范 v2](包规范-v2.md)。

## 六个包

| 包 | 用途 |
| --- | --- |
| UE4SS-FrostrailCore | 固定版 UE4SS、公共 Lua 支持库、F8 设置窗口 |
| 辅助 | 穿墙高亮、头灯、打开容器时 R 全部拿取、基础负重 |
| 快存与格子锁 | 把背包物品放进附近已有同类物品的箱子；锁定格子不参与快存，整理时保留位置 |
| 分拣台 | 输入、输出格默认扩为 15 和 10，可调整 |
| 种植 | 七种莓果、果实和蘑菇默认投入 1 个，600 秒后产出 5 个；配方可调整 |
| 堆叠 | 可堆叠物品上限默认 ×10，可按类别调整，单位重量不变 |

快存指存入附近箱子，不是保存战役。堆叠关闭、卸载或降低倍率前，要在 Mod 仍启用时把超量堆叠拆回目标上限并保存，避免数量丢失。

## 设置与开关

左侧勾选启停，箭头调整 UE4SS 入口顺序。依赖需要一起启停时，管理器会列出联动项，确认一次。无 UE4SS 入口的包排在最后。

选中 Mod 后，在右栏修改设置。勾选、回车、离开输入框或结束表格编辑时自动保存；“恢复默认”只恢复本页列出的设置。未显示的配置键保持不变。

游戏运行时，管理器的文件操作和设置只读，日志仍可查看。带 F8 标记的字段可在游戏内按 F8 调整，点击“应用并保存”后立即应用。其他设置下次启动生效。F8 文案按游戏语言选择中、英文。

原生改键在游戏“设置 → 控制”里调整。辅助默认 R 拿取容器全部物品、F 开关头灯；快存、锁格和 F8 沿用游戏档案里的动作绑定。

## 更新

新版 ZIP 直接拖入即可更新，保留开关、顺序和配置。六个包已填写公开 GitHub 来源，可用“检查更新”“全部更新”或详情里的单包更新。版本文字不同就会提示，允许回退。管理器本身更新时，关闭旧窗口，下载新版 EXE 替换即可。

“安装 → GitHub 链接…”接受仓库首页或 `tree/分支/目录` 链接。多个 Release ZIP 会列出来供选择，不需要 GitHub 账号。请求被限流时可以稍后再试，或下载 ZIP 后本地安装。

## 卸载

在详情页点击“卸载…”，阅读作者提示，可勾“保留设置”。依赖它的包会关闭，并显示缺少前置。具体清理与保留规则见[卸载会删什么](包规范-v2.md#卸载会删什么)。管理器不会恢复游戏存档里的状态，也不会替你拆堆。

## 日志与排查

列表中的 ⚠ 表示日志里有上次启动失败；详情会显示首条错误。“日志”页先列失败项，再列原文。可以切换上次启动、管理器操作或某个 Mod，筛选级别和搜索文字。

“导出诊断包”生成本地 ZIP，包括摘要、管理器日志、UE4SS.log 尾部和所选 Mod 的日志。导出的副本会替换用户目录和游戏路径，不自动上传。没有报错标记不等于玩法、存档或多人已验证。

安装状态和包缓存随游戏目录保存在 `FrostrailModData/`。界面语言、窗口大小、上次游戏路径和更新检查时间存于 `%LocalAppData%/Yuuka/FrostrailModManager/ui.json`。Mod 的 `config.json` 在自己的 UE4SS 文件夹内。
