# 人物皮肤 · 同人 / Character Skins · Fan Works

给人物皮肤菜单加两款同人人物：Meltical · 魔女和黄色奶蛙。同人作品单独成包。

需要 UE4SS-FrostrailCore 和人物皮肤 0.3.0 或更新版本。装好后打开背包，点「人物皮肤」，同时安装这四个包时，两款排在菜单最后。用法、背部装备开关和多人说明见人物皮肤本包。只改你自己屏幕上的样子，想换装的人自己装就行。

- **Meltical · 魔女**：紫色长裙、发饰和衣袖。
- **黄色奶蛙**：保留原模型的圆肚子、短腿和蛙爪，所以半跪时会压进雪里。第一人称用原蛙爪和原版手持动作。

## English

Adds two fan-work characters to the Character Skins menu: Meltical · Witch and Yellow Milk Frog. Fan works ship in this separate package.

Requires UE4SS-FrostrailCore and Character Skins 0.3.0 or later. Open the inventory and choose **Skins**; with all four packages installed, these two characters appear last. See Character Skins for usage, the back equipment toggle and multiplayer. Only your own screen changes.

- **Meltical · Witch**: long purple dress, hair ornaments and sleeves.
- **Yellow Milk Frog**: keeps the original round belly, short legs and frog hands, so it sinks into the snow when kneeling. First person uses the frog's hands with the game's own held-item animations.
