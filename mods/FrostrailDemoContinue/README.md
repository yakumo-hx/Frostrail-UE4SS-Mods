# Demo 续玩

Frostrail Demo 打到苔原终点就结束了。装上这个包，可以接着跑苔原关卡。作者 Yuuka，MIT 许可。

## 怎么用

1. 退出游戏。在 Mod 管理器里装好前置 `UE4SS-FrostrailCore`。
2. 把 `FrostrailDemoContinue-0.1.0.zip` 拖进管理器，启用“Demo 续玩”，启动游戏。
3. 到区域终点时，选 `CONTINUE IN THE TUNDRA BIOME`。

没有设置，也没有快捷键。和辅助包互不依赖，可以只装这一个。

## 要知道的

- **要在到终点之前启用。** 存档已经停在 Demo 结束页的，它救不回来。
- **停用以后：** 重启游戏就回到原版的关数上限。超过上限的存档还能读，但下一次过出口会进 Demo 结束页。关卡进度不会倒退。
- **内容：** 后面还是苔原的地图，没有新的区域。
- **多人：** 没测过。
- 它不改游戏文件。适用于 Demo Build 25985740。

## English

Requires UE4SS-FrostrailCore. Close the game, drag this ZIP into the Mod Manager, enable it and start the game. At the biome ending, choose **CONTINUE IN THE TUNDRA BIOME**. No settings, no hotkeys, and it works without Assist.

- Enable it before you reach the ending. It cannot rescue a save that is already on the Demo end screen.
- After disabling it and restarting, the original level limit is back. Saves past the limit still load, but the next exit ends the run. Progress is never rolled back.
- You keep playing tundra maps; there are no new biomes.
- Multiplayer is untested. No game files are modified. Built for Demo Build 25985740.
